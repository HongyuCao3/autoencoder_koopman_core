## 一、S2 拟合规格（纯 CPU，S1 判分落盘当天完成）

两套模型**同一 split、同一评估**（20 折按题分，held-out 一步 MSE；null 三个：`const` / `turn_mean` / `stateless`）：

**M0 恒等观测量**（论文可比基线）
$$y_{t+1}=a\,y_t+b\,u_t+c$$
直觉：下一轮满足比例由上一轮按比例保留，提醒加一个常数增益。$y_t\in\{0,\tfrac13,\tfrac23,1\}$，$u_t\in\{0,1\}$ 是本轮是否重述约束（`--contemporaneous-v` 口径），$a$ 自持续，$b$ 提醒增益，$c$ 常数。

**M1 提升观测量 + 状态依赖增益**
$$z_{t+1}=A\,z_t+\big(B_0+B_1\,y_t\big)\,u_t+d$$
直觉：状态多了"哪条掉了"与"是否在照抄"，提醒增益随当前满足比例变化（K3 已见 Δy 从 0.205@y=0 单调降到 0.055@y=1）。$z_t=[y_t,c_t,e_t,u_{t-1}]\in\mathbb R^6$，$A\in\mathbb R^{6\times6}$，$B_0,B_1\in\mathbb R^6$，$B_1$ 是增益对 $y_t$ 的斜率（ERGO 里叫 $b_2$）。$y$ 的方程是 $z$ 的第一行。

| 闸门 | 判据（跑前定） | 过了 → | 不过 → | 填哪格 |
|---|---|---|---|---|
| **G-S2-1 状态**（不变） | M0 或 M1 在 ≥14/20 折打过三个 null 里最好的 | 开 S3 | 关线（§七死亡条件 3 一并核） | 拟合表 |
| **G-S2-2 可控**（不变） | $b$（M0）95% CI 不含 0 且为正 | 同上 | 记录并交裁决 | 前提 (i) |
| **G-S2-5 提升是否值钱** | M1 相对 M0 的 held-out MSE 下降在 ≥14/20 折成立 → S3 控制器用 M1；否则用 M0 | **只决定 S3 用哪个模型**，不阻塞 | — | 拟合表第二行 |
| **G-S2-6 增益状态依赖** | $B_1$ 首分量的自举 95% CI 不含 0 | 记录；过则 S3 预期为 S1 级 | 记录；不过则 S3 预期为 S2 级（不劣于先知） | 前提 (iii) |
| **G-S2-7 记忆（持久性）** | S1b 配对：$u_t$ 对 $y_{t+2}$ 的配对差 CI 不含 0（$y_{t+1}$ 已由 K3 答） | 写进论文"有记忆"句，替代 `defense` 的 *consistent with* | 写"一步效应、无持久" | 前提 (ii) |
| **G-S2-4 样本量**（不变） | 用 late-$y$ 配对 sd 反推 S3 每臂轨迹数；>150 条/臂停下报告 | 定 S3 seed | — | — |

**离线退化检查（记录项，不是闸门）**：用 M1 对预算 $k$ 下全部固定日程枚举预测终窗 $\bar y_{15:20}$；若最优日程在 ≥80% 题上是同一条，S3 仍跑，但预注册预期降为"不劣于最优固定日程"。这是 ERGO 计数预算退化教训的**前置版本**，零 GPU。

## 二、S3 臂表（Opus 签字后才写 sbatch）

预算 $k$ 在 S2 后定：取 $k$ 使 `constant_remind` 在 S1 的 late 增益的一半可被 $k$ 次提醒买到（用 M0 的 $b$ 与 $a$ 估算）；候选 $k\in\{3,5\}$，**签一个**。N=40 题、T=20、3 seed、保真 harness、题集与 S1 逐字相同。

| 臂 | 动作 | 新增生成 | 它回答什么 |
|---|---|---|---|
| `zero_control` / `constant_remind` | 复用 S1 | 0 | 上下界 |
| `fixed_even_k` / `fixed_late_k` | 等间隔 / 集中在 t≥15 的 $k$ 次 | 2 × 2400 | 最优固定日程（先知） |
| `random_k` | 等预算随机时机 | 2400 | 不看状态的自适应 |
| `mpc_time_k` | M0 或 M1（按 G-S2-5）全视野 MPC，终窗目标 $\bar y_{15:20}$，只选时机 | 2400 | **RQ3 主臂** |
| `mpc_dir_k` | 同上，但提醒**只重述 $c_t$ 中已掉的那条**（掉多条则全部） | 2400 | 方向动作的增量 |

生成 5 × 2400 = 12000 次 @ batch 40（S1 实测 1.1–2.2 s/次）→ **3.7–7.3 h**；判分两份读出 36000 次 × 0.11 s ≈ 1.1 h + 加载。**一个作业三相**（生成 + 14B 判分 + 4B in-loop 判分），产物目录全新。in-loop 状态用 4B 自判（S0 已校准，方向性差 0.02 写进局限）；报告数字只出 14B。
**饱和处理（S1 试点已见 `constant_remind` t20 天花板份额 0.545）**：MPC 目标加惩罚项 $\lambda\cdot$`inserted_tokens`，$\lambda$ 取使 `constant_remind` 不是最优解的最小值，跑前算出写死。

| 主判据（按 (题,seed) 配对 bootstrap 10000，`default_rng(0)`） | 含义 |
|---|---|
| **P1** `mpc_time_k − random_k` 95% CI 下界 > 0 | 看状态选时机 > 不看状态 → **S2 级** |
| **P2** `mpc_time_k − max(fixed_even_k, fixed_late_k)` CI 含 0 或下界 > −0.03 | 不劣于先知 → 与 P1 合为 **S1 级** |
| **P3** `mpc_dir_k − mpc_time_k` CI | 方向动作是否有增量（不预测方向） |
| P4（诊断） | mpc 花费轮次分布；按 $y_{t}$ 分层的 Δy | 解释赢/输在哪 |

P1 不过 → RQ3 写"前提全满足仍无自适应收益"，**不调 $k$、不换目标函数重跑**。
