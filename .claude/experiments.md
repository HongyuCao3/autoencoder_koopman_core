# 实验规则（开闸门 / 提交 GPU 作业 / 开新任务线）

先读 `.claude/global.md`。账本：`docs/LEDGER.md`。

## 提交 GPU 作业前（逐条过，缺一条不提交）

1. **不要自行提交。** 写好 sbatch、用真实 argparse 干跑验证，然后**停下来等用户裁决**。
2. **运行时估计** + 依据的假设（题目数 / seed 数 / 轮数 / `max_new_tokens` / 显卡）。
3. 逐条核过**不覆盖任何已有产物**，输出路径全新。
4. 在 `docs/LEDGER.md` §3 追加一行，**"它改变了哪个决定"必须填得出来**。填不出来 →
   这个作业不该跑。
5. 检查配额：**最近 10 个作业里"仪器"超过 5 个 → 停止提交，向用户报告并要求裁决。**
6. **并发提交的作业不要各自做 editable install。** 多个作业同时向
   `/scratch/hcao2/envs/persona_drift_pilot` 装同一个包会竞争
   （`__editable__.persona_drift_control-0.1.0.pth` 缺失 → 作业 1 分钟内 FAILED）。
   2026-09-08 一批并发提交里因此死了两个（15696222、15696227），其中一个**未被察觉、未重提**。

## 提交之后

**批量提交后必须核一遍 `sacct`**，不要只看 `squeue`——失败的作业不在 `squeue` 里。

```bash
sacct -u hcao2 -S <date> --format=JobID,JobName%32,State,Elapsed -X
```

把每个作业的终态回填 `docs/LEDGER.md` §3。**失败作业要么重提、要么在账本里写明为什么不重提**
——15696227 就是失败后既没重提也没记录，导致 ALT 臂组静默缺了一个臂。

分类口径——**仪器** = judge 有效性 / 读出量程 / 执行器权威 / base rate / 退化检查 /
重判 / 方向校准 / 信号 screening；**方法** = 辨识数据、闭环评测、baseline 对比、消融。
历史基线（98 个作业回填）：仪器 47 / 方法 48 / 基建 3，接近 1:1。

## 闸门准入三行

**每个前置闸门必须先填这三行，缺任何一行不允许开：**

| 字段 | 要求 |
|---|---|
| 过了 → | 下一步跑什么。**必须是主线动作**（辨识 / 闭环评测 / baseline），不能是另一个闸门。 |
| 不过 → | **关闭这条线** 或 **换仪器**。二选一，写死，不许留"再看看"。 |
| 它填论文哪张图/表 | 图表编号或"不填"。填"不填"的闸门需要用户显式批准。 |

**若"过了"和"不过"的答案都是"再设计一个闸门"→ 禁止开这个闸门，直接跑主线。**

> 依据：`docs/experiments/koopman_fast_track_plan.md` §5——用来否掉"有没有状态"的三个数字，
> 没有一个是 Koopman/DMDc 需要的量。**Koopman 拟合的 held-out 一步误差本身，就是比任何
> 代理闸门更强的仪器检验。** 默认顺序：**主线先跑，仪器怀疑并行挂着、不阻塞主线**，
> 只在主线出结果后用来解释结果。

## 仪器修复触发重跑时

**不要默认全量重跑。** 先用产物里的 harness 指纹（`.claude/global.md` → *产物与谱系*）
筛出真正受影响的 run，只重跑那些。ERGO 闭环比较被跑了三遍（9→3→6 = 18 个作业回答同一个
问题），成因就是无法判断哪些产物过期。重跑范围要向用户报告后再提交。

## 开一条新任务线

按顺序，缺一步不许提交第一个 GPU 作业：

1. 跑 `/research-experiment-design`（skill 在 `~/.claude/skills/`），产出 kill criterion。
2. 写下**死亡条件**："什么证据下我放弃这条线。" 写不出来 = 这条线没有可证伪的主张，不要开。
3. 写下它在论文里那段的 **3 句话** + 它要填的**那张图/表的空壳**。
   **实验若不填那个空壳，不跑。**
4. 在 `docs/NAMING.md` 登记代号，在 `docs/LEDGER.md` 开一个 campaign 段。

## 结果落盘

实验完成后填 `docs/experiments/*.md` 的结果表，数字口径严格按 `.claude/global.md` →
*报告口径*（独立重判 × ≥3 seed × `mean ± std (n)`）。**不要覆盖文档已有的结构与结论段**，
只填结果。
