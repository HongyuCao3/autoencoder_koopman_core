\section{When the Command Effect Cannot Be Estimated from the Logged Trajectories}
\label{app:A7_command_channel}

On four of the seven modeling columns of Table~\ref{tab:prediction} the command channel carries no information beyond the memory state.  % m5, updated 2026-09-24 to match Sec. 4.6 wording
The collection logs show it. On the two tasks that record a per-turn command, the applied command equals the target on every transition: 2268 of 2268 on sentence length, 240 of 240 on sentiment. The tracking error spans $[-0.40, +0.88]$ on sentence length across those same transitions.  % figs/_fig_report.json fig_mechanism sources; moved from Sec. 4.4 on 2026-09-21
The two joint tasks record no per-turn scalar command.  % m5 notes; 'rank test below' removed 2026-09-24 (no such test in this appendix)
The prediction design therefore cannot estimate an independent command effect on those four columns.  % nc_1; nc_8; n_main_014 n_main_046 n_main_030 n_main_110
On the remaining three columns, defense, constraint and CEFR, the paired difference between the reported model and the Memory w/o command row of Table~\ref{tab:prediction} is +0.0121, +0.0015 and +0.0061, with intervals containing zero.  % contrasts.ours_minus_memory_no_action defense=0.0121 (n_main_149), constraint=0.0015 (n_main_133), tsar_cefr=0.0061 (n_main_181)
This is a property of how those trajectories were collected, not a result about the controller.  % m5 notes
The control experiments of \S\ref{sec:exp_control} are the test of the command channel.  % D11
