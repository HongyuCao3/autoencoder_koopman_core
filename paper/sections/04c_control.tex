\subsection{Constraint Satisfaction under Predictive Control}
\label{sec:exp_control}

\textbf{Question.} RQ2a and RQ2b: whether predictive control built on the learned operator raises constraint satisfaction over the same frozen model with no control, and over the two white-box latent controllers.
\textbf{Setup.} Setup, benchmarks and baselines follow \S\ref{sec:exp_setup}; Table~\ref{tab:control} reports the constraint-satisfaction score defined there.

\textbf{Findings, gain over the uncontrolled baseline.} Predictive control raises constraint satisfaction over the uncontrolled baseline by +14.5 points on Qwen3-4B and +14.8 on Qwen3-8B, averaged over eleven subtasks as point estimates with no seeds or intervals.  % c5; control_deltas: Qwen3-4B/Koopman-Base=14.47, Qwen3-8B/Koopman-Base=14.76
The driver is that scoring happens on a candidate's predicted trajectory, not its immediate effect.  % m3
This lets the controller pick a command that differs from the target while the attribute is still moving.  % m3

\textbf{Findings, gain over the white-box controllers.} The same controller exceeds the stronger white-box baseline, RE-Control, by +5.2 points on Qwen3-4B and +5.7 on Qwen3-8B, again as point estimates with no interval.  % c6; control_deltas: Qwen3-4B/Koopman-RE-Control=5.25, Qwen3-8B/Koopman-RE-Control=5.65
% smallest per-subtask margin (+2.4 / +2.7, IFBench UWC; n_bench_013 n_bench_035 n_bench_057 n_bench_079) removed from prose 2026-09-21: table-readable
The access requirement is uneven, and it is uneven against us: RE-Control reads the model's activations, while the predictive controller sees only text.  % choice_3 notes
% c7 (best in all 22 cells; n_bench_012 n_bench_022 n_bench_056 n_bench_066) now stated only in the underlined conclusion; the
% "hardest to satisfy in one shot" sentence removed 2026-09-21: no definition or number supported it.

Taken together, \uline{predictive control raises constraint satisfaction over the uncontrolled baseline in all twenty-two model-by-subtask cells, a count rather than a significance claim, which answers RQ2a yes. It exceeds both white-box controllers in the same twenty-two cells at a weaker access requirement, which answers RQ2b yes.}
