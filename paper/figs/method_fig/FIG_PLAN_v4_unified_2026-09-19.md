## 一、2×2 的问题：按章节切，而不是按论证切

v26 里同一对象的重复绘制：$s_t$ 5 次以上，$K$ 4 次（含 $\widehat K$），仿射一步 3 次，读出行 $C$ 3 次。根源是四块对应正文四个小节，而组件（状态）、对象（模型）、两种用法（拟合它 / 反复调用它）不是同一层级，并列就必然重画。

更深一层：即使去重，"学习"那一块也不该占四分之一版面。最小二乘拟合是任何线性模型都有的步骤，图上画它不增加读者对本文的理解。图真正要回答审稿人的两个问题是：**为什么一个线性算子能描述"提示—回复"这种非线性黑箱过程**（3.1 的 Why 段），以及**这个线性结构如何直接变成控制器**（3.3 与 Algorithm 1）。这两个问题都是关于**结构**的，不是关于训练的。

## 二、设计：两条平行的"空间"，左半建模、右半控制

Koopman 方法的经典图就是一张交换图：下面一行是原空间里的非线性演化，上面一行是观测量空间里的线性演化，竖直箭头是观测映射。本文的实例正好能填进去，而且**命令通道**给了这张图一个本文独有的元素：同一个 $c_t$ 既经协议 $\mathcal{P}$ 进入下行的真实系统，又经列 $B$ 进入上行的线性模型。

```
            ┌── Modeling: why a linear operator fits ──┐ ┊ ┌── Control: what linearity buys ─────────────────────────┐
 上行  Observable space (linear)                         ┊
   s_t ──[K]──(+)──▶ ŝ_{t+1} ──[K]──(+)──▶ ŝ_{t+2}       ┊   c ∈ C_t ▫▫▫ ─▶ [ K^h  Σ K^j(Bc+b) ] ─▶ ŷ_{t+h|t}(c) ─▶ [迷你图 vs r] ─▶ Ĵ_t ▬▬ ─▶ argmin ─▶ c_t★
   (L+1 delay coordinates      ▲ B c_t   ▲ B c_{t+1}      ┊   (from s_t; closed form; no LLM call)                                                    │
    = observables)             │         │                ┊                                                                                           │
   ▲ V, shift          ▲ V, shift        ▲                ┊                                                                                           │
   │                   │                 │  ← 观测映射（竖直）                                                                                           │
 下行  Text space (nonlinear, black box)                  ┊                                                                                           │
   u_t ──▶ [p_θ] ──▶ o_{t+1} ──▶ u_{t+1} ──▶ [p_θ] ──▶ o_{t+2}                                                                                         │
   ▲ P(x,H_t,c_t)                                                                                                                                     │
   └───────────────────────────────────────────────────────────── c_t★ → P ◀──────────────────────────────────────────────────────────────────────────┘
```

**左半（建模）回答"为什么能"。** 下行是真实系统：提示 $u_t$ 进冻结的 $p_\theta$，出回复 $o_{t+1}$，验证器 $V$ 读出标量，滑进窗口——这是非线性、黑箱、文本空间。上行是同一过程在**延迟坐标**上的像：$s_t$ 经 $K$、加 $Bc_t+b$ 得 $\widehat s_{t+1}$，再走一步得 $\widehat s_{t+2}$——线性。竖直的 "$V$, shift" 箭头是观测映射，把下行每一步接到上行对应的状态上；图形上"下行弯、上行直、竖直箭头对齐"就是 Koopman 论证本身：**非线性留在被观测的对象里，线性出现在观测量上**。命令 $c_t$ 画在两行之间，一个单格、两支箭头：向下经 $\mathcal{P}$ 变成提示，向上经 $B$ 进入算子。这一个图元回答了 3.1 P4"一条指令凭什么有命令坐标"。$s_t$ 旁的花括号标 $L+1$ 并配 minicap "delay coordinates = observables"，对应 3.1 P3"延迟坐标就是观测量字典"。可选 lifting 按 D33 保留为上行之上一条淡色直角旁路（$E_\phi$ 一次），表示字典可换。

**右半（控制）回答"建模之后怎么控"。** 从分界线处的 $s_t$ 出发，三个候选命令进入**一个** $K^h$ 块（标 `\symKpow` 与 $\sum K^j(Bc+b)$，即 eq:closed_form_rollout），出三条预测轨迹进迷你图与绿色目标 $r$ 比较，得三条代价横条，argmin 选出 $c_t^\star$。$K^h$ 块是"上行是线性的"这一事实的直接后果——闭式多步、无需再调 LLM——这就是"建模之后如何控制"的因果链，读者从左半的直线读到右半的 $K^h$ 就明白了。$c_t^\star$ 沿右侧竖线下到下行、经 $\mathcal{P}$ 回到左端的 $u_t$：闭环。Algorithm 1 的 read → shift → roll & score → argmin → send 就是沿这个环走一圈。

**去掉了什么。** 学习不再有版面：$K,B,b$ 从哪来由图注一句"fit offline by least squares"交代（正文 3.2 有公式）。A 的"同一 $y_t$ 两种趋势"小图删除，它论证的是窗口长度，正文 3.1 P2 承担。左栏删除，因为下行 + 竖直箭头 + 右侧回路已经把 Verification / Memory update / KOMPAS / Prompt construction / Inference 五步全部画在环上，再保留就是第二次重复。

## 四、版式与尺寸

- 画布 13.97 × 5.6 cm。两条水平"空间"带（`band` 样式，圆角浅底）：上行 Observable space 高 2.2，下行 Text space 高 1.6，带间 0.9 留给竖直观测箭头与 $c_t$ 单格；两带各在左上角一个 `tag`（"Observable space, linear" / "Text space, black box"，≤4 词）。

- 左半：两个真实时间步（$t\to t+1\to t+2$），x 0.4–6.4；上行状态列在 x≈0.9 / 3.1 / 5.3，下行 $p_\theta$ 在 x≈1.8 / 4.0；竖直观测箭头三条，命令单格两处（$c_t$、$c_{t+1}$，第二处淡色）。
- 右半：$K^h$ 块（x 7.4–8.6，居右半视觉中心）、迷你图（8.9–10.4）、代价条（10.7–11.9）、$c_t^\star$（12.4）；候选集三格在 $K^h$ 块下方左侧，总线直角进块；右侧竖线 x≈12.9 下到下行，沿下行底边从右向左回到 $\mathcal{P}$（x≈0.5）。

- `minicap` 配额 ≤ 5：delay coordinates = observables / linear in observables / nonlinear, black box / closed form, no LLM call / optional lifting。

## 五、需要用户定的三件事

1. **左半画一步还是两步。** 两步（$t\to t+2$）能让"上行直线、下行弯路"的对比成立，也让第二个 $c_{t+1}$ 表明命令每步都可变；代价是宽度多 2cm。一步则更紧凑但"线性演化"只剩一个箭头，说服力弱。建议两步，第二步的 $B,b$ 不展开、$p_\theta$/$V$ 用淡色。
2. **右半的滚动画成一个 $K^h$ 块（推荐）还是三根渐淡列。** $K^h$ 块把"线性 ⇒ 闭式"直接写在图上，且不重画状态；渐淡列更直观但又是一排状态。
3. **训练是否留一个最小痕迹。** 选项：完全不画（推荐，图注一句）；或在左半 $K$ 块下方一个 `minicap` "least squares, offline"。
