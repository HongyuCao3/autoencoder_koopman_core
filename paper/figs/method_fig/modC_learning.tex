% modC_learning.tex — module C: learning the model from interaction data.
% v3 (2026-09-19, post CP2-redo; replaces modC_training.tex). §3.2 states two
% things, and this module draws exactly those two, left half then right half:
%   (1) the training set is overlapping windows sliced off recorded reading
%       streams -- each slide gives one transition (s_t, c_t, s_{t+1});
%   (2) fitting (K,B,b) to those transitions is a single least-squares
%       problem (eq:identification), closed form, with s_t/c_t/K/B/b drawn
%       as the SAME blocks and colours module B uses (readers connect the
%       two by glyph identity, not by a drawn line between the panels).
% This replaces the old three-loss / two-autoencoder training diagram
% wholesale: no \EncNet/\DecNet, no L_rec/L_lin/L_pred, no q_t, no D_psi(.),
% one lossline instead of two crossing ones, zero trapezoids.
