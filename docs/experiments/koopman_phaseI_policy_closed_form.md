# Phase I 策略的闭式刻画：a11、边际收益零点 y*，以及 59 个"不插"点的逐点核对

和 [koopman_case_study_design.md](koopman_case_study_design.md) 同一条线的后续记录，但**不
引入任何新实验、新拟合、新 GPU job**：全部数字都是从两份已经存盘的产物里直接读出来、再用
模型自身的公式手算出来的。

**新开一次对话想知道"Phase I 那个 v 对齐后的 `koopman_mpc_interaction` 策略，用一句话说到底
是什么规则"，看这份文档。**

**结论先说：它就是一条阈值规则——`y_{t-1} <= 0.75 就插提醒，y_{t-1} = 1.0 就不插`。**
Phase I 那 80 行（良性 96 行）里的每一次决策，无一例外由这条规则解释，48/48 与 64/64 零失配。
下面把这条规则从 $A,B_1,B_2,b,C$ 推出来，并说明它为什么必然是抖动的。

## 模型

$\nu{=}1,\mu{=}2$，`contemporaneous_v=True`，状态 $z_t = [y_{t-1},\, u_{t-2},\, u_{t-1}]$，
增广动作 $v_{\text{aug}} = [u,\; u \cdot y]$（`modeling/interaction_lift.py`），因此
$B_1 = B[:,0]$、$B_2 = B[:,1]$：

```
A  = [ 0.7036255345  -0.0247578773  -0.0548555715 ]
     [-7.63358e-09    9.00863e-09    0.9999999696 ]
     [-1.10941e-07   -0.3333332330   2.94934e-09  ]
B1 = [ 0.2790290175,  2.63286e-09,  0.6666665639 ]
B2 = [-0.3205158049,  7.63358e-09,  2.22798e-07 ]
b  = [ 0.2542711547,  1.25909e-08,  0.3333333318 ]
C  = [ 0.9999999786,  1.06906e-08,  1.43352e-08 ]
```

$C \approx e_1^\top$，所以读出的就是状态第一维；$A$ 的下 2×2 块 $\approx [[0,1],[-1/3,0]]$ 是
滞后动作槽位的移位结构，不是学出来的动力学。

## 1. $a_{11}$：稳态存在，"稳态"这个说法站得住

$$a_{11} = 0.703626$$

而且它**就是谱半径**：下 2×2 块的特征值是纯虚共轭对，$|\lambda| = \sqrt{1/3} = 0.577350$，
小于 $a_{11}$。所以

$$\rho(A) = 0.703626 < 1 \quad\Longrightarrow\quad (I-A) \text{ 可逆，稳态唯一且渐近稳定}$$

**不需要退回去讲直流增益，可以正大光明地讲稳态。** 两个开环稳态：

| 输入 | 稳态 $y$ |
|---|---|
| $u \equiv 0$（从不插） | **0.790783** |
| $u \equiv 1$（每轮插） | **0.767706** |

$u \equiv 1$ 那一行有个坑，值得在页上点一句：因为 $v_{\text{aug}} = [1, y]$ **依赖状态本身**，
这不是一个普通的常值输入，不能套 $(I-A)^{-1}(B_1+b)$。正确做法是把交互项并进系统矩阵，
$\tilde A = A + B_2 e_1^\top$（$\tilde A_{11} = 0.383110$，仍稳定），稳态取
$(I-\tilde A)^{-1}(B_1+b)$。若误用朴素不动点迭代 $y \leftarrow C(I-A)^{-1}(b+B_1+B_2 y)$ 会
发散——因为该迭代的增益是 $C(I-A)^{-1}B_2 = -1.081456$，绝对值大于 1。发散的是那个迭代，
不是系统。

直流增益（如果那页还是要写）：$C(I-A)^{-1}B_1 = 0.807162$，$C(I-A)^{-1}B_2 = -1.081456$。

## 2. 边际收益的零点 $y^*$：两个版本，差 0.015

### 2.1 一步式（教科书写法）

$$C(I+A) = [\,1.7036255,\; -0.0247579,\; -0.0548555\,]$$
$$C(I+A)B_1 = 0.4387906,\qquad C(I+A)B_2 = -0.5460389$$
$$\boxed{y^*_{\text{linear}} = -\frac{C(I+A)B_1}{C(I+A)B_2} = 0.803589}$$

### 2.2 控制器真正在算的东西

`control.py::KoopmanMPCController._simulate(z, a, remaining_steps=1)` 在第二步还有一个
`max` over $a_2$：

```
value(a) = C·step(z,a) + max_{a2} C·step(step(z,a), a2)
```

两个分支的**后续最优动作并不总是相同**，所以真实 margin 不是 $y$ 的线性函数，
$C(I+A)(B_1+B_2 y)$ 只是"两支第二步都选 0"时的特例。数值求根：

$$\boxed{y^*_{\text{actual}} = 0.788068}$$

对照（右列与 `interaction_model_report_valigned.json` 的 `decision_replay.records` 逐位相符）：

| $y_{t-1}$ | $C(I+A)(B_1+B_2y)$ | 控制器真实 margin |
|---|---|---|
| 0.00 | +0.438791 | +0.349357 |
| 0.25 | +0.302281 | +0.238530 |
| 0.50 | +0.165771 | +0.127703 |
| 0.75 | +0.029261 | +0.016876 |
| 1.00 | −0.107248 | **−0.107248**（唯一重合点） |

只有 $y=1$ 重合（那里两支第二步都选 0）。另外真实 margin 对 $z_3 = u_{t-1}$ 有微弱依赖：
$y=1$ 时 $z_3{=}1$ 给 −0.104361 而非 −0.107248，量级 0.003，**不改符号**。

### 2.3 操作上两者等价

`y_probe` 是判官分 /5，落在 $\{0, 0.25, 0.5, 0.75, 1.0\}$ 的 0.25 网格上（Phase I 两个 arm
的全部 176 行都没有例外，也没有 NaN）。0.788 和 0.804 之间没有网格点，所以两个 $y^*$ 给出的
**操作阈值完全一样**：

$$\text{插提醒} \iff y_{t-1} \le 0.75$$

## 3. 核对：Phase I 的 59 个"不插"点

对两个 arm 的每一行，按 `_current_state` 的口径重建 $z_t = [y_{t-1}, u_{t-2}, u_{t-1}]$
（`contemporaneous_v=True` $\Rightarrow$ `shift=1`，`min_len = max(nu-1, mu-shift)+1 = 2`，
即 turn 1、2 恒定 fallback 到 0），复算 margin 并与实际落盘的 `u_remind` 比对：

| | 攻击 arm | 良性 arm |
|---|---|---|
| 总行数 | 80 | 96 |
| `u_remind=0` | **59** | **87** |
| 其中 turn 1–2 强制 0（$z$ 为 None，历史不足） | 32 | 32 |
| 真实"不插"决策 | **27** | **55** |
| 真实"插"决策 | 21 | 9 |
| **margin 符号 vs 实际动作** | **48/48 ✓** | **64/64 ✓** |

**那 59 个点的构成：32 个根本没做决策，剩下 27 个真实"不插"点全部是 $y_{t-1} = 1.0$、
margin $= -0.107248 < 0$、全部落在 $y^* = 0.7881$ 右侧，没有一个例外。** 良性 arm 的 87 个
同理：32 个强制 + 55 个真实决策，同样全是 $y_{t-1} = 1.0$。

按 $y_{t-1}$ 分档（攻击 arm 的 48 次真实决策）：

```
y_prev=1.00  n=27  margin=-0.107248  ->  全部 action=0
y_prev=0.75  n=15  margin=+0.016876  ->  全部 action=1
y_prev=0.50  n= 3  margin=+0.127703  ->  全部 action=1
y_prev=0.25  n= 1  margin=+0.238530  ->  action=1
y_prev=0.00  n= 2  margin=+0.349357  ->  全部 action=1
```

良性 arm（64 次）：`1.00 -> 55 个 action=0`；`0.75 / 0.50 / 0.25 -> 6 / 2 / 1 个 action=1`。
良性流量在 55/64 ≈ 86% 的决策点上 $y_{t-1}$ 仍是 1.0，这正是"只用 9/96 次提醒"的直接来源——不是策略保守，
是良性场景本来就极少跌出 1.0。

## 4. 一个副产品：这个策略必然抖动

$$y_{ss}(u\equiv1) = 0.7677 \;<\; y^* = 0.7881 \;<\; y_{ss}(u\equiv0) = 0.7908$$

$y^*$ **夹在两个开环稳态之间**。所以闭环不存在停在某一侧的可能：一直插会把 $y$ 拉到 0.7677
（低于 $y^*$，但那时 margin 为正、还想继续插），一直不插会把 $y$ 推到 0.7908（高于 $y^*$，
于是停手）。策略只能在两者之间来回切。Phase I 观测到的 21 插 / 27 不插**不是调出来的比例，
是这个模型的结构决定的**。

这也给 [koopman_case_study_design.md](koopman_case_study_design.md) 的"目标现象 4"（horizon
是否真正生效）补了一个更干净的答案：第二步的 `max` 确实改变了 margin 的数值（把零点从 0.804
挪到 0.788），但在 0.25 的判官网格上**没有改变任何一个决策**——horizon=2 相对 horizon=1
贪心，在这批数据上是数值上生效、行为上不生效。

## 5. 局限（写页子时别越界）

1. **这是模型内部的自洽刻画，不是"这条阈值规则是对的"**。$y^*$ 是拟合出来的 $A,B_1,B_2,b,C$
   自己蕴含的零点；模型本身的 held-out rollout MSE 是 0.0703，还**劣于**同报告里的参照
   ARX（0.0510）和 `richer_abs_sign`（0.0430）。方向学对了不等于预测更准。
2. **两个稳态 0.7908 / 0.7677 差 0.023，比判官网格的一格（0.25）小一个数量级**，落在模型
   自身误差里。"插提醒的稳态更差"这句话**不要**当成结论讲，它只是解释抖动机制时的中间量。
3. $y^*$ 落在 0.75 和 1.0 之间的空档里，离两个网格点都不近（0.038 / 0.212）。这说明阈值判
   得稳，但也说明**这批数据没有能力把 $y^*$ 定位得更精确**——任何 $(0.75, 1.0)$ 内的
   $y^*$ 都会给出完全一样的 48/48 拟合。
4. 全部核对只覆盖 Phase I 这 8 个 held-out 攻击 × 2 seed（+ 良性 16 × 6 轮）。零失配说明的是
   **"复算口径正确、规则完整刻画了这个控制器"**，不是"规则泛化"。

## 复算方式

登录节点没有 python，本次全部数值用 `awk` 手写线性代数复算（3×3 高斯消元 + `_simulate`
的逐字重写）。任何人在 compute node 上用几行 numpy 都能复现，需要的只有上面那组
$A,B_1,B_2,b,C$ 和三条定义：

- `step(z,a)`: $z' = Az + B_1 a + B_2 (a\cdot z_1) + b$，读出 $Cz'$；
- `sim(z,a)` = $C\,\texttt{step}(z,a) + \max_{a_2} C\,\texttt{step}(\texttt{step}(z,a), a_2)$；
- `margin(z)` = `sim(z,1) - sim(z,0)`，`action = 1 iff margin > 0`。

判据：复算出的 margin 必须与 `decision_replay.records` 里对应 $z$ 的值逐位相同（本次成立），
否则说明口径对错了。
