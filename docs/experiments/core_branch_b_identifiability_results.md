## 读法

1. **截距混杂没有让 v1 的估计产生偏差**：在同一 prompt、同一段历史下只改所问字数，得到的斜率与 v1 跨 prompt 估计相差 0.003。v1 的随机化本已让 prompt 截距与命令无关（$R^2\le0.003$），v2 证实这一点在数值上成立。
2. **历史类型不改变平均增益**：v1 的历史是随机命令，v2 的分叉前缀是落盘的「反复问目标」历史，两者 $CB$ 一致。所以「命令权限随历史而变」这个担心，在平均意义上没有被支持。
3. **仅用主轨迹时秩亏、$R^2=1$**：在新采集的语料上复现了 headroom §二（只用落盘协议，$B$ 无定义）。

## 探索性（事后、未事前签、无区间，不进判词）

按分叉轮次 $k$ 拆开的配对 $\widehat{CB}$：

| seed | k=2 | k=4 | k=6 |
|---|---|---|---|
| 0 | 0.686 | 0.714 | 0.817 |
| 1 | 0.669 | 0.774 | 0.778 |
| 2 | 0.630 | 0.736 | 0.785 |

三个 seed 都是 k=2 最低、k=6 最高（约 0.66 → 0.79）：越往后，模型越跟所问的数，也就是命令增益可能随轮次上升。这是事后切分，每格约 80 个分叉点，没有区间，**只作为假设**，不改变上面的判词，也不触发新采集。若要检验，可以用已落盘的数据补区间（零 GPU），但需要先签。
注意它与读法 2 不冲突：读法 2 比的是两种历史下的**平均**增益；这里是同一种历史下增益随轮次的**变化**。若成立，它意味着线性定常 $B$ 是轮次平均值，交出去时应同址注明。
