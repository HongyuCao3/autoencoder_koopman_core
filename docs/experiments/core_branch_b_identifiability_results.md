## 读法

1. **截距混杂没有让 v1 的估计产生偏差**：在同一 prompt、同一段历史下只改所问字数，得到的斜率与 v1 跨 prompt 估计相差 0.003。v1 的随机化本已让 prompt 截距与命令无关（$R^2\le0.003$），v2 证实这一点在数值上成立。
2. **历史类型不改变平均增益**：v1 的历史是随机命令，v2 的分叉前缀是落盘的「反复问目标」历史，两者 $CB$ 一致。所以「命令权限随历史而变」这个担心，在平均意义上没有被支持。
3. **仅用主轨迹时秩亏、$R^2=1$**：在新采集的语料上复现了 headroom §二（只用落盘协议，$B$ 无定义）。
