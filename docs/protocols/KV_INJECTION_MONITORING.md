# KV 注入作为控制通道：机制、实现与 Koopman 监控协议（草案 v0.1，2026-08-27）

本文件独立于 `DATA_COLLECTION_PROTOCOL.md`，描述把 KV 缓存注入（KV injection / cache steering）作为人格漂移控制的第三个执行器通道时，需要的实现要点、监控量、实验步骤与已知限制。两份协议的接口约定（表结构、切分、readout）以本文件第 5 节为准，若与前者冲突，以本文件为准。

## 1. 机制与"是否需要训练"

结论：**不需要任何梯度训练或新参数**。两类代表方法：

- Memory Inception（Liu 等，Yale/Princeton，arXiv 2605.06225）：把提醒文字套模板 → 用冻结模型前向一次记录各层隐状态 → 在选定层/注意力单元上，把隐状态归一化后用模型**自带的** K、V 投影矩阵投成 key/value → 作为额外槽位插入缓存。存的是加 RoPE 之前的 key，槽位不占对话位置、不随生成失效。唯一的准备步骤是**校准选择器**：用一小组参考文本给每个注意力单元打分（其 query 对目标槽位的对齐程度相对参考槽位的裕度），取 top-k 单元、top-m 层，形成冻结的选择器。换提醒内容只需换槽位内容，选择器不动，可见对话文本不变。
- Cache steering（Belitsky 等，arXiv 2507.08799）：从对比样本构造 steering 向量，一次性加到 KV 缓存，之后不再干预；相比逐 token 激活 steering，延迟更低、对超参更稳。

## 2. 在控制模型里的位置

KV 注入不是"每轮说一遍"的输入，而是每轮每个 token 都被读取的**持续输入源**，效果介于输入 u 与改变被控对象 A 之间。建模时给它一个可连续调节的强度 m_t：

```
z_{t+1} = A z_t + B u_t + B_m m_t + c
```

式中 z_t 为延迟嵌入的遵循分状态，u_t 为常规提醒强度（通道 A），m_t 为本轮注入强度（通道 D），B_m 为注入通道的效果列，A、B、c 与主协议相同。

m_t 的三种连续化实现（择一，首选第一种）：
1. 槽位 value 向量乘以缩放系数 β ∈ [0, 1]（key 不变，只改被读出的内容）；
2. 保留的槽位数量比例（按校准得分截断）；
3. 对槽位 key 的注意力 logit 加偏置 δ。

## 3. 监控量（每轮记录）

| 记号 | 含义 | 来源 |
|---|---|---|
| `y_probe` | 遵循分 | 主协议 readout |
| `a_bank` | 选定单元对注入槽位的注意力质量（各头取均值；GQA 下按组聚合） | 前向传播中的注意力权重 |
| `a_sys` | 同一批单元对 system prompt token 的注意力质量 | 同上 |
| `m` | 本轮注入强度 | 控制/激励设定 |
| `bank_id` | 槽位内容版本（中途换内容时递增） | 记录 |

`a_bank` 与 `a_sys` 用于第 4 节层次二；两者同时记录可直接比较"注入槽位是否像 system prompt 一样被逐轮遗忘"。

## 4. 三个监控层次（成本递增）

**层次一：输出空间效果辨识（上下文重放）。** 用主协议已采的对话历史作为固定上下文库，对同一段历史在 m ∈ {0, 0.5, 1} 下各续写一轮，最小二乘同时得到 A、B、B_m。指标：B_m 的各分量（推力方向/大小）；有无注入时 A 的最大特征值（漂移衰减率）差异。成本：一批前向 + 一轮生成。

**层次二：注意力质量作为可观测量。** 把 a_bank 与 y 一起放进状态：

```
[y_{t+1}, a_{t+1}]ᵀ = K [y_t, a_t]ᵀ + B_m m_t + c
```

式中 a_t 为第 t 轮的 `a_bank`，K 为 2×2 转移矩阵。K 中 a 行的对角元是"槽位注意力保持率"：接近 1 表示槽位持续被读，明显小于 1 表示注入也在被遗忘；K 的 y←a 非对角元是"注意力质量对遵循分的传导强度"。对照量：用 `a_sys` 替换 `a_bank` 重复辨识，得到 system prompt 注意力的保持率（对应 Harvard persona_drift 的注意力衰减机制）。

**层次三：残差定位。** 用 m=0 辨识出的 (A, B) 预测 m>0 的轨迹，残差方向即 B_m 方向；比较不同提醒文本的残差方向是否一致，判断是否可用单一强度旋钮而不区分措辞。

## 5. 接口约定（覆盖主协议的对应条目）

- 表结构在主协议列上新增：`m, a_bank, a_sys, bank_id, injected_layers, injected_units`。
- 激励设计：m_t 与 u_t 独立抽取；30% 轨迹只激活 m 通道（u ≡ 0），30% 只激活 u，40% 两者同时随机，以便分别辨识 B 与 B_m 及其交互。
- 切分仍按 `system_prompt_id`。
- 校准选择器用 train split 的 10 条 prompt 生成，冻结后用于全部 split。

## 6. 实验步骤

1. 实现槽位插入（HF `past_key_values`，处理 RoPE 前 key 与 GQA 维度），用 5 条 prompt 验证注入后模型输出可读、遵循分上升。
2. 校准选择器，记录被选层与单元。
3. 层次一：上下文重放 → A、B、B_m。
4. 层次二：记录 a_bank / a_sys → 保持率对比。
5. 若保持率 < 0.9，做"槽位刷新"实验：由预测的 a_t 触发换 bank 内容，对比固定周期刷新。
6. 把 m 作为第三个通道接入 MPC，与"每轮推"（u）对比同等遵循分下的代价。

## 7. 已知限制

- 仅适用于可访问缓存的开源模型；闭源 API 不可用。
- 选择器对模型特定，换模型需重新校准。
- 强度 m 通过缩放 value 实现时效果未必线性，可能需要提升坐标（保留 AE 结构的理由之一）。
- 不加注入采集的数据辨识出的 (A, B) **不能直接预测** B_m（见第 8 节）。

## 8. 可辨识性说明：无注入数据能否预测注入效果

不能直接预测。B_m 是"m 方向上的响应"，最小二乘只能辨识数据中被激励过的输入方向；m ≡ 0 的数据对 B_m 没有任何信息，这是系统辨识的基本事实（持续激励条件）。无注入数据能提供的是：A（惯性/衰减率）——在注入不改变模型内部机制的假设下可作为先验，使 B_m 的辨识只需少量带 m 的样本（固定 A，只解 B_m，未知数从 O(n²) 降到 O(n)）；以及层次三的残差定位手段。若注入显著改变了衰减率（层次一发现 A 的最大特征值随 m 变化），则应改用 m 依赖的 A(m)，或在提升坐标中建模。
