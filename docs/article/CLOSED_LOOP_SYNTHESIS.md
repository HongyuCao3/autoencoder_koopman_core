## 一、四列逐列：谁打平或压过 Ours

| 列 | 打平/压过 Ours 的臂 | 它具体是什么 | Ours − 它（主量） | 代价（Ours vs 它） |

### 措辞红线（写正文前先钉死）

- **除 `defense` 外没有一列能说 baseline「赢了」**，只能说「打平，且 Ours 更贵」。写成
  「简单 baseline 打败了 Koopman-MPC」是超出数据的。
- `tsar_cefr` 的「被支配」是**代价**主张不是 RMSE 主张。代价是逐轨迹确定的，不带误差棒；
  RMSE 那一侧 CI 含 0。
- `defense` 的「为负」**显著性取决于重采样单元**（攻击 ★ / 轨迹跨 0），且 8 个攻击对聚类
  bootstrap 偏少。不看单元能说死的只有一句：**没有打赢，点估计为负。**
- `defense` 全列 `judge_kind=self`（`global.md` 具名例外）：自判 = 单向漏检、systematically
  低估效应。**例外不外溢到其余三列。**

## 二、它是两类 baseline，不是一类

- **(A) 等代价开环固定日程**——零状态信息，预算花在一个事前或事后挑好的位置：
  `fixed_t5` / `best_fixed_schedule` / `fixed_last` / `fixed_ladder`。
- **(B) 手写标量反馈规则**——用状态，但只用一个标量、一条 if-else，无模型、无视界：
  `threshold` / `greedy_targeted` / `greedy_reactive`。

**Ours 对 (A) 四战零胜；对 (B) 三次打平（一次名义略好、两次名义略差）。**
两类同时打平，排除了「Ours 输在没用状态」和「Ours 输在没规划」这两种解释——它们互相排除对方。

## 四、效应量阶梯：动作本身 vs 重排预算

这是这批工作最硬的一个发现，因为它在**四个设定、四种读出、三个模型类**上重复出现：

| 列 | 动作本身买到 | 把同一份预算重排买到 |
|---|---|---|
| `defense` ⚠self | 满剂量 − `zero_control` **+0.119** late（终点口径 +0.244） | Ours − `fixed_t5` **−0.0250** |
| `constraint` | Ours − `zero_control` **+0.1163 ± 0.0128**（1.87×MDE） | **+0.0014 ± 0.0145**（0.05×MDE） |
| `gsm8k_sharded` | reset 权威 **+0.1810** [+0.0862,+0.2845] | 恒等（差 = 0） |
| `tsar_cefr` | D-2 执行器权威 **−0.1356 ± 0.0099**（3.78×MDE） | −0.0073 / +0.0096（均跨 0） |

**动作本身 ≈ +0.12～0.18；重排预算 ≈ 0.00～0.01。差一个数量级。**

`tsar_cefr` 那列还隔离出一个**比控制更大的自由度**：`dp_degeneracy = 1.0`（199 题 DP 路径全部
等于相邻阶梯）使 `dp_path` 与 `fixed_ladder` 走同一条级别路径、步数都 ≈1，唯一差别是 prompt 家族
（命名绝对级别 vs 相对动作），差 **0.0395**；而相对家族内三条控制策略的全距只有 **0.0129**。
**prompt 家族效应是控制策略效应的 3 倍**，且是那张表里唯一越过 MDE 的落差。

> **这一条的推论要写进正文**：在这类设定里，**选对指令家族比选对动作序列重要**。
> 它也是 `koopman_mpc − dp_path` 那个「过了」的签死主对比（−0.0730 [−0.1396,−0.0081]）
> 主要买到的东西——**引用该对比的任何地方必须同址带 `dp_degeneracy = 1.0`。**

## 五、对 claim 的影响

### 必须撤（正文里若有残留，按此改）

1. **「Koopman-MPC 在等代价下优于固定日程」——四列零支持。**
   `MAIN_TABLE_DESIGN.md` §零裁决 1 已把 RQ3 降级为「闭环在什么条件下才买得到东西」；
   `tsar_cefr` 是 2026-09-14 才落盘的第四列，**它没有改变结论、只把 n 从 3 抬到 4**，
   正文若还写「三条线」要改成四条。
2. **「第 3 行跨列为零是 core 的局限、行为线会翻正」——已被第十一列证伪。**
   `tsar_cefr` 是三项条件（动作写入下一步输入 / 过冲有代价 / 动作是真随机化的四值分类）
   **都满足**的那一列，仍然为零。改写成正面结论：**第 3 行为零是这批任务族的性质，不是某条线的缺陷。**
3. **「记忆假设成立」只能写条件性**：core 7 个可判任务 3 个显著支持、**1 个显著反对**
   （`average_word_length_t5` −0.409，n=14）、3 个分不开。

### 可以留，而且现在比之前更强

4. **闭环的零是有机制的、被量出来的，不是调参失败。** 2026-09-14 之前这句话靠 `defense`
   的因果 oracle 一条扛，现在有 §三 的四种量法各自给出同一个零，其中两种不经过我们的控制器。
5. **代价轴让「打平」变成有内容的结论**：三列里 Ours 有两列更贵，`tsar_cefr` 最清楚
   （3.2× token 换统计上相同的误差）。这不是失败的实验，是**闭环在这类任务上的价格**的一次实测。

## 六、能 present 什么（按证据强度排）

### ① 算子类的选择：延迟嵌入够用，非线性不值（最硬，Table 1）

- `ours − Markov` 在**五个信息量足够的列上全部显著为正**：core 三列 +0.603 / +0.312 / +0.235，
  `constraint` +0.234，`tsar_cefr` +0.0487。**记忆是被测出来需要的。**
- `ours − AE`、`ours − LSTM` 在所有有信息的任务上 **|Δ| < 0.03**（行为线 ≤0.05）**且符号在任务间翻转**，
  配对 bootstrap 精确到能把 0.005 判显著。
- 卖点：**简单性是被测出来的，不是被假设的。**

**边界（同址必带）**：不能写「统计上不可区分」——有两格名义显著，其中 `character_length_t5` 上
**LSTM 更好 −0.031**。`tsar_cefr` 列 LSTM −0.101 / AE −0.032 都没越过平凡 null，**那是样本量不足
（597 轨迹 × 6 步），不得当作「非线性无用」的证据**，措辞不与其余十列合并。

### ② 一个可迁移的负结论 + 它的机制（最有信息量，Table 2）

**「在 LLM 多轮设定里，执行器权威大、动作时机的状态依赖小」**，四个设定重复。
这比「我们的控制器更好」更难做也更少有人做——要得到这个结论，必须先把执行器权威、读出量程、
可分性、上界四件事分别量出来，缺任何一件这个零都能被归因成仪器问题。

**边界**：任务族只有四个，都是「文本属性/行为在多轮里被提醒或改写推动」这一类。
**不得写成关于 LLM 控制的普遍命题**，写成「在这四类设定上」并点名三条前提。

### ③ 事前判定闭环值不值得投的判据链（潜力最大，但**只有单向**）

在烧闭环 GPU 之前，用零 GPU 或一个小作业回答「闭环能不能买到东西」。四件工具都已落地，
并在四条线上做出了与后来昂贵闭环实验**一致**的预测：

| 工具 | 成本 | 先于闭环给对了答案的列 |
|---|---|---|
| 日程可分性检查 | 零 GPU | `gsm8k_sharded`（=1，构造退化）、`constraint`（=1，S2 两次） |
| 因果 oracle 上界（回放已落盘轨迹） | 零 GPU | `defense`（+0.0063 跨 0，早于闸门 R1 关线） |
| 反事实树上确界 | 1 个作业 2h23m | `tsar_cefr`（0.7752，headroom 0.0130，早于 Table 2 五臂） |
| Table 1 第 3 行 `ours − 扣住 u` | 零 GPU | 十一列 |

**硬边界**：`tsar_cefr` 是**预注册**的阳性对照——该线计划 §7.1 签的是「本列第 3 行显著不为零」，
实测 **+0.0061，CI 含 0**。**阳性对照没兑现，所以这条判据只在零侧受过检。**
2026-09-15 用户裁决已把交付物重签为**单向的事前否决判据**：第 3 行为零 ⇒ 等代价下不要投闭环；
**非零侧未受检**。要把 ③ 讲成完整的方法贡献，缺的是**一个第 3 行真非零、且闭环真为正的任务族**——
现在没有，也不该靠改辨识口径去凑（那是第二次修同一条仪器链，见 `global.md` → *同一个仪器只修一次*）。
