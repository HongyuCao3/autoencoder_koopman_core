## 〇、一句话

计划押的是「动作直接写入下一步输入、过冲有代价 ⇒ 第 3 行不为零、闭环为正」。两条都落空：第 3 行 +0.0061（CI 含 0），
Ours 对开环阶梯打平（−0.0073）却贵 3.2 倍 token，对三条 if-else 手写规则也打平（+0.0096，符号不利），锚趟里是三臂最差。
**根因不是算子拟合坏了（那是次要的），是这个任务在结构上就没有给「规划」留空间**：可观测量每步精确到手、动作效果一步兑现、
自由演化近乎恒等——这是一个**全观测的一阶积分器**，对它来说按距离分档的贪心规则就接近最优。
反事实树在 GPU-2 之前就量出了这件事（最优反馈策略对手写规则的余量只有 **0.0130**），但死亡条件 D-2.5 比的是「反馈 vs 开环」而不是
「规划 vs 贪心」，于是这条信息没有阻止 GPU-2。

我 09-13 的五条判据里有两条写错了方向（F2、F3），一条没被落地（F1）。下面逐条对账。

## 二、为什么没成功：五层原因，按重要性排

### 2.1 根因：任务是「全观测一阶积分器」，贪心就接近最优

直觉：开车时如果你每一秒都能精确看到与目标的距离、油门一踩车就到位、松开油门车就停在原地，那么「离得远就多踩、离得近就少踩」这一条规则已经是最好的开法——预判未来毫无用处。规划只在**刹车有延迟、车有惯性、或者路况会变**时才值钱。

`tsar_cefr` 的三个实测事实正好把这三样都排除了：
- **每步精确观测**：$\ell_t$ 由固定分类器即时给出，没有观测延迟；
- **动作效果一步兑现**：`step_down` 的效应完整体现在 $\ell_{t+1}$，之后不再展开（文本已被改写完）；
- **自由演化近乎恒等**：`copy` 91% 逐字返回输入，即 $\ell_{t+1} \approx \ell_t$ 当 $u_t = 0$。

把三条合起来，系统就是

$$
\ell_{t+1} = \ell_t + b(\ell_t)\,u_t + \varepsilon_t ,
$$

其中 $\ell_t$ 是当前 CEFR 期望级别，$u_t$ 是本步的简化力度，$b(\ell_t)$ 是随状态变化（靴地板附近变小）的一步增益，$\varepsilon_t$ 是分类器与生成的噪声。
对这样的系统、在终点平方误差目标下，**最优策略是「按当前距离选力度」的静态映射**，不需要历史、不需要视界。
`greedy_reactive` 的三条 if-else 就是这个映射的粗版。反事实树给出的数——最优箱可测策略 0.7752 对手写规则 0.7882——正是在说「粗版已经收满了 98%」。

**推论**：只要 MPC 的算子有一点点误差，它就只能比手写规则更差，因为上面没有空间可赢。锚趟里 Ours 最差，Table 2 里 Ours 打平，都是这个结构的后果，不是解码方式或视界长短的后果。

### 2.2 我的判据 F2 与 F3 把「状态持久」误当成「需要预判」

09-13 我写：F2 惯性 ✅（下一步输入就是上一步输出）、F3 动作跨时间 ✅（改写留在后续所有步的输入里）。
两条都是事实，但它们说的是**状态**持久（谱半径 0.96、半衰期约 19 步），不是**动作效应**持久。
规划要有价值，需要的是后者：$u_t$ 的效果在 $t+2, t+3$ 还在展开（脉冲响应长度 > 1），或者动作受速率限制、现在不动以后就来不及。
在 `tsar_cefr` 里脉冲响应长度恰好是 1——动作一次到位。**状态是积分器、动作是瞬时的**，这正是贪心最舒服的组合。

判据应改为：**F2′ 动作到效果有延迟或需多步展开**（脉冲响应长度 ≥ 2）；**F3′ 存在速率限制或动作间的跨期耦合**（今天做了明天就不能做，或做多了要付回撤代价）。`tsar_cefr` 两条都不满足；有一点速率限制的迹象（本模型跳不了两级，`B2→A2` 原始奖励 −0.196），但目标级固定，所以速率限制没有和「要提前动」结合起来。

### 2.3 F1 没有被落地：目标级在轨迹内是常数

09-13 的 T1 写的是「时变参考跟踪」，理由是有惯性的系统跟一条会变的目标必须提前动。落到 TSAR 上时目标级变成了每条轨迹固定的 B1 或 A2——**F1 在实例化时丢了**，而它是「需要预判」的唯一外部来源。
剩下的题间差异（源级不同）被 `fixed_ladder` 一次读 $\ell_0$ 就拿走了：它其实是**用初始观测的前馈**，不是零信息开环。这也是它能打平 Ours 的原因。

### 2.4 第 3 行量的是方差份额，不是权威——所以它十一列为零并不奇怪

第 3 行 `Skill_H(ours) − Skill_H(扣住 u)` 问的是：知道动作序列后，4 步滚动的 MSE 降了多少。
D-2 说一次 `step_down` 平均压 −0.13。四步随机动作（各 1/4 概率）引入的 $\ell$ 方差约

$$
\mathrm{Var}_{\text{action}} \approx H \cdot \mathrm{Var}(b\,u) \approx 4 \times (0.13)^2 \times 0.19 \approx 0.013 ,
$$

其中 $H=4$ 是视界，$0.13$ 是一步增益，$0.19$ 是四值均匀动作的方差因子（$\tfrac14\cdot\tfrac34$）。
而 $\ell$ 的题间方差约 $0.5^2 = 0.25$。动作解释的份额约 **0.013 / 0.25 ≈ 5%**，再被算子拟合误差吃掉一部分，落到 +0.006 是**数量级上应当如此**。

这条要写进论文的方法讨论：**第 3 行对「动作有没有进算子」是一个低灵敏度的检验**——它只在动作引入的方差与题间异质性可比时才亮。四条线里题间异质性都占主导（`constraint` 的状态项大部分是持久题目难度，S2 已诊断），所以第 3 行为零与 D-2 权威显著并不矛盾，也**不能**单独解读为「动作不进算子」。
它作为单向否决判据仍然可用（零 ⇒ 别投闭环），09-15 的重签是对的；但它的零侧「4/4 有实例」里，**有一部分是仪器的灵敏度，不全是任务的性质**，这句要同址带上。

### 2.5 次要但真实：算子把两个动作排反、权威低估一半

$B_\ell$：`half_step_down` −0.0696 < `step_down` −0.0665，MPC 一次 `step_down` 都不选；$B$ 的量级只有无模型配对差的一半（算子把另一半归给 $K\xi$）。
成因是 ridge + 状态与动作共线（低起点的题更常在后段、后段动作效应更小）。这是可修的（按状态分层估 $B$、或把 $B$ 写成 $b(\ell)$），**但即使修好也赢不了**——上面已经没有 0.013 以上的空间。所以它不是这条线失败的原因，只是让失败更难看。仓库按「同一仪器只修一次」不修，是对的。

### 2.6 一条流程教训：D-2.5 比错了对手

D-2.5 的判据是「最优反馈策略 − 最优开环」，判 +0.2241 ★ 不触发，于是投了 GPU-2。
可同一棵树上同址就算出了「最优反馈策略 − 手写贪心 = 0.0130」，比 Table 2 的 MDE 0.095 小 7 倍。
**Koopman-MPC 要赢的从来不是开环，是手写规则**——它多花的是模型与视界，必须证明模型与视界值钱。正确的死亡条件应是

$$
G_{\text{plan}} = J(\pi^\star_{\text{history}}) - J(\pi^\star_{\text{myopic}}) ,
$$

其中 $\pi^\star_{\text{history}}$ 是允许看历史与视界的最优策略，$\pi^\star_{\text{myopic}}$ 是只看当前读出的最优静态规则，$J$ 是主量。
$G_{\text{plan}} <$ MDE ⇒ 不投闭环 GPU。这个量在树上是零 GPU 可算的，09-14 已经算出来了，只是没有被写成判据。

## 三、计划做对了什么（不能因为结果为零就一起否掉）

- **闸门纪律在每一步都兑现**：G-T1 的 100% 判据被指出设错后，按留痕重签而不是改仪器；G-S1 触顶按预注册剔题；D-2.5 策略类在树落盘前签死；GPU-2 五项裁决在提交前签字。零结果是干净的。
- **反事实树是本仓库最好的一个新仪器**：67,660 次生成、2h23m，一次性给出所有 4 步策略的精确值，让「反馈值多少、规划值多少」变成可算的数。它应当成为以后任何闭环线的前置标配。
- **第四次复现了同一个规律**：执行器权威大（0.12–0.18）、动作时机的状态依赖小（0.00–0.01），四个设定、四种读出、三个模型类。这是论文里最硬的经验发现。
- **隔离出一个比控制更大的自由度**：prompt 家族效应 0.0395 是控制策略全距 0.0129 的 3 倍。「选对指令家族比选对动作序列重要」是一条别人可以直接用的结论。

## 四、还有什么可能的任务

先把筛选判据改对，再看候选。改后的判据只保留真正决定「规划有没有价值」的三条，其余降为必要条件。

| 判据 | 问什么 | 零 GPU 怎么量 |
|---|---|---|
| **P1 规划余量** | 最优历史依赖策略对最优静态规则的余量 $G_{\text{plan}}$ ≥ 2×MDE | 在辨识算子或反事实树上做后向归纳，两类策略都精确解 |
| **P2 动作效应多步展开或有速率限制** | 脉冲响应长度 ≥ 2，或存在「现在不做以后来不及」的约束 | 开环随机激励数据上估脉冲响应；算子 $B$ 的多步累积 |
| **P3 目标或扰动在轨迹内变化且可预告** | 参考序列 $r_t$ 非常数，或扰动可从历史预测 | 设计属性；扰动可预测性用留一交叉验证 |
| 必要条件 | 执行器权威（D-2 式）、读出量程（D-1 式）、过冲有代价 | 已有工具 |

### 候选 A：多目标耦合调节（core `vector_count_stage2_t10` 的闭环化）——最值得先做零 GPU 检查

**为什么它可能满足 P1**：三维读出（词数、平均词长、逗号数）由同一段文本承载，一条「加长」指令会同时改变三者。当动作在各维上有交叉耦合时，逐维独立的 if-else 规则会互相打架，而模型化的 MPC 能协调。这是 P1 有余量的经典来源，也是 Table 1 上记忆效应最大、样本最足的一列（`ours − Markov` +0.312 ★，540 条轨迹）。
**数据已在盘上**：540 条轨迹、T=10，Table 1 第 6 行的算子已拟合。
**零 GPU 先做**：① 看算子 $B$ 的非对角项（交叉耦合）是否显著；② 在算子上用后向归纳算 $G_{\text{plan}}$（最优历史/视界策略 vs 最优逐维静态规则）；③ 植入对照：把 $B$ 对角化后 $G_{\text{plan}}$ 须掉到 0。
**死亡条件**：非对角项 CI 含 0，或 $G_{\text{plan}}$ < 2×MDE ⇒ 不投 GPU。
**风险**：core 的动作是连续指令（目标值），动作空间大，反事实树不可行，只能靠算子模拟（比树弱一层）。

### 候选 B：速率受限的时变参考跟踪（把 F1 真正落地）

`tsar_cefr` 已经量到一条速率限制：模型跳不了两级。若目标级在轨迹中途变化（例如前 3 步要 B1、后 3 步要 A2，且**提前告知**），那么「在切换前一步就开始降」才来得及——这正是预判有价值的最小配置。
**零 GPU 可先在已有的反事实树上判**：树是 4 步全枚举，可以直接算「目标在第 3 步切换」时最优历史策略 vs 最优静态规则的差。P1 一算就知道。
**弱点**：任务是构造出来的，benchmark 故事弱；正文只能作为「规划余量 > 0 时 Koopman-MPC 确实能兑现」的机制演示，不是应用主张。
**成本**：若树上 $G_{\text{plan}}$ 过线，GPU 臂与 GPU-2 同规模（约 11 分钟实测量级）。

### 候选 C：效应延迟展开的执行器（system prompt 持续型动作）

让动作写进 system prompt 并持续 k 轮再撤下，动作效应跨多轮展开（P2）。「何时开、何时关」成为有记忆的决策。
**风险已知**：ContextEcho 报单次锚定无衰减 → 可能是饱和持久动作，退化成「越早越好」；需先量脉冲响应。
**成本**：新 harness、新开环采集，1–2 个 GPU 作业；在截稿前不现实，列为 future work。

### 明确不再做的

- 在 `tsar_cefr` 上修算子（分层估 $B$、换 ridge）：余量 0.013 < MDE，修好也赢不了；且是第二次修同一仪器链。
- 换解码/换视界重跑 Table 2：机制不随这些改变（锚趟已证）。
- 在四条已关或打平的线上换读出。

## 五、对论文的直接后果

1. **正面闭环结果在本次投稿里不再是目标。** 四列为零、机制被四种独立方法量出、判定判据链已单向成立——这是一篇诊断型论文的完整证据。`CLOSED_LOOP_SYNTHESIS.md` §六 的三条 present 顺序（算子类选择 > 可迁移的负结论 + 机制 > 单向判定判据）是对的。
2. **要补一段方法讨论**：第 3 行为零有一部分是仪器灵敏度（§2.4），零侧判据的强度要如实降级；同时把 $G_{\text{plan}}$（规划 vs 贪心）作为正确的事前判据写出来，并用 `tsar_cefr` 的树演示它在 GPU-2 之前就给出了正确预测（0.0130 < MDE）。这把一次失败的正例变成方法贡献的一部分。
3. **`tsar_cefr` 在正文的角色**：不是「第四个零」的简单叠加，而是**把一步权威与规划视界内的可利用结构分开的那一列**——权威 3.78×MDE，规划余量 0.013。四列里它把这两件事分得最干净。
4. 候选 A 的零 GPU 检查（半天到一天 CPU）值得在截稿前做：若 $G_{\text{plan}}$ 有量，它是 future work 里唯一有数据支撑的方向；若为零，Limitations 里可以写「在 core 的多目标列上也未发现规划余量」，让四个零变成五个。

## 六、小结

`tsar_cefr` 没按预期成功，是因为它在结构上是一个全观测、动作瞬时兑现、自由演化恒等的一阶积分器，按距离分档的贪心规则已接近最优，规划没有空间；我 09-13 的判据把「状态持久」误当成「需要预判」，且时变目标在落地时被丢掉了，而死亡条件 D-2.5 比的是反馈对开环而不是规划对贪心，所以树上已算出的 0.013 余量没有拦住 GPU-2。
剩下的可能任务只在「规划余量 $G_{\text{plan}}$ 可事前量出且过线」的地方：首选 core 三维耦合读出的多目标调节（数据已在盘上，零 GPU 可判），其次是速率受限的时变目标跟踪（可直接在已有反事实树上判）。
无论哪条，本次投稿应按诊断型论文写，并把「规划 vs 贪心」的事前判据与第 3 行的灵敏度局限一并交付。
